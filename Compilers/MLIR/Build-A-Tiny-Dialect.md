# Building a tiny dialect (hands-on)

The MLIR plan's practical goal: a tiny dialect of my own, walked parse → canon → lower → LLVM with `mlir-opt` at every stage. Toy is the template; this note is the recipe and the commands to run.

## The recipe

1. **Define the ops in TableGen/ODS** — one `.td` file per op (`def AddOp : Op<Toy_Dialect, "add", [Pure]> { ... }` with `arguments`/`results`/`assemblyFormat`), generated by `mlir-tblgen -gen-op-decls -gen-op-defs` (see [TableGen](TableGen.md)). Start with `Pure` arithmetic ops and a `ConstantOp`.
2. **Wire the build** — the [CMake-Guide](CMake-Guide.md) pattern: `mlir_tablegen`, then `add_mlir_library` for the dialect plus its `registerDialect` entry point.
3. **Add canonicalization patterns** — `let hasCanonicalizer = 1`, then DRR `def`s (`(MyAddOp $x, 0) -> $x`) so `-canonicalize` does something (see [DRR](DRR.md), [Canonicalization](Canonicalization.md)).
4. **Write the lowering** — a `DialectConversion` pass: target = arith/memref (or affine), patterns rewriting `my.add` → `arith.addi`, `my.constant` → `arith.constant`, via `RewritePattern` with `matchAndRewrite` (see [DialectConversion](DialectConversion.md)).
5. **Lower to LLVM** — the standard ladder: `-convert-to-llvm` (memref→`!llvm.ptr`, arith→`llvm.*`; see [LLVM-Dialect](Dialects/LLVM-Dialect.md)), then `mlir-translate --mlir-to-llvmir` produces a real `.ll`.

## The mlir-opt pipeline

```bash
# parse + canonicalize
mlir-opt test.mlir -canonicalize

# the toy-style ladder: own dialect -> affine -> scf -> cf -> llvm
mlir-opt test.mlir -canonicalize -convert-my-to-affine -convert-affine-to-scf -convert-scf-to-cf -convert-to-llvm

# the standard Toy route (with the tutorial's passes)
mlir-opt test.mlir -toy-combine -convert-toy-to-affine -convert-toy-to-llvm
```

Each stage's output is printable, so the "did it work" check is just reading the IR between passes.

## Inspecting pass effects

`-mlir-print-ir-after-all` dumps the IR after *every* pass — the best way to see what each pass changed:

```bash
mlir-opt test.mlir -canonicalize -mlir-print-ir-after-all 2>&1 | less
```

Or name one pass (`-mlir-print-ir-after=canonicalize`) and add `-mlir-print-ir-before-all` for the before/after pair; `-mlir-pass-statistics` prints per-pass stats. On the Toy example, `-toy-combine -mlir-print-ir-after-all` on `transpose(transpose(x))` shows the two transposes collapse to one — the DRR fold (see [Toy-Tutorial](Toy-Tutorial.md) Ch3) doing visible work.

## What "done" looks like

The full loop: `.mlir` in → `mlir-opt` prints canonicalized IR → conversion passes produce affine → `-convert-to-llvm` gives `llvm.*` → `mlir-translate --mlir-to-llvmir` yields a `.ll` that `lli` can run. If the generated `.ll` executes and prints, the tiny dialect is real.
