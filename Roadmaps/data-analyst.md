# Data Analyst

Data analysts turn raw data into **insight for decisions**: dashboards, reports, SQL queries, and statistical analysis. The most accessible of the data roles — no heavy engineering or research required to start.

## Core skills

- **SQL** — the #1 skill. Joins, window functions, aggregation, performance basics.
- **Spreadsheets/BI tools**: Excel, Tableau, Power BI, Looker for dashboards.
- **Statistics**: descriptive stats, A/B testing, hypothesis tests, confidence intervals, correlation vs causation.
- **Python (pandas, matplotlib)**: data wrangling and visualization as you grow.
- **Storytelling**: turning numbers into clear recommendations for non-technical people.
- **Domain knowledge**: the business domain you work in matters more than ML.

## Typical day-to-day

- Writing SQL to answer questions; building dashboards; running A/B test analyses; cleaning messy data; explaining findings to stakeholders.

## Roadmap to get there

1. SQL fluency + Excel.
2. Statistics fundamentals (distributions, p-values, A/B tests).
3. A BI tool (Tableau/Power BI).
4. Python: pandas + plotting.
5. Optional progression: analytics engineering → data science (add ML — see [ml-engineer](ml-engineer.md)).
