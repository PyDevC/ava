# AI Engineer

The AI Engineer is the practitioner who **builds and ships AI products** — applying existing models/frameworks/APIs to real problems, rather than inventing new algorithms. Think "software engineer with ML depth" more than "ML researcher".

## Core skills

- **Software engineering**: Python, git, testing, APIs, containerization (Docker), cloud basics.
- **Applied ML**: training/fine-tuning models with PyTorch; classic ML (sklearn) for tabular; evaluation and data work.
- **LLM stack**: prompting, RAG (retrieval), fine-tuning, tool calling, agent orchestration; knowing when to use an API vs a local model.
- **MLOps basics**: experiment tracking (MLflow/Weights & Biases), model serving, monitoring drift.
- **Math**: enough linear algebra / calculus / probability to read papers and debug training.

## Typical day-to-day

- Data prep/cleaning → training/eval loops → prompt/agent development → deployment.
- Writing evaluation harnesses and red-teaming model outputs.
- Gluing models into products (guardrails, caching, cost control).

## Roadmap to get there

1. Python + data structures; git.
2. Classic ML course (sklearn, trees, linear models — see my [algorithms](../MachineLearning/algorithms/PLAN.md) notes).
3. Deep learning (CNNs, Transformers — see [Transformers](../MachineLearning/deeplearning/Transformers.md), [An-introduction-to-convolutional-neural-networks](../MachineLearning/deeplearning/An-introduction-to-convolutional-neural-networks.md)).
4. PyTorch fluency (see [Explore](../PyTorch/Explore.md)).
5. LLM application layer: prompt engineering, RAG, fine-tuning, agents.
6. Deployment: FastAPI/Streamlit, Docker, model serving, monitoring.
